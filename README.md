# mao2009 / loach

C# / .NET を中心に、OSS と開発ツールを作っています。

- **PSXRecompStudio** — PlayStation 1 の静的再コンパイル・解析を研究する OSS
- **PureSharp** — C# に参照透過性・不変性の検証を持ち込む Roslyn Analyzer
- **ArchitectureAnalyzer** — アーキテクチャルールをコンパイル時に検証する Roslyn Analyzer
- **ArchLintCpp** — C++ 向けアーキテクチャ検証ツール
